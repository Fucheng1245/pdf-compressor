## 瓶颈和处理

旧版 high 的 cProfile 累计耗时约 24.6 秒，其中 22.4 秒在清理对象；PNG 预测器解码约 20 秒。
旧版 mid 累计约 34.6 秒，其中 30.9 秒在图片处理。这些是分析器下的数字，有额外开销，不作为用户等待时间。

1. 不可达对象先通过引用图清理，包含孤立循环，避免解码被丢弃的编辑数据。
2. 去重比较完整对象字典与原始编码字节，不为哈希解码图片；不同编码保持分开，保守处理。
3. 满足颜色、位深、行宽等约束的 PNG 预测器图片使用 Pillow 原生解码；不兼容时回退原流程。共享透明遮罩继续保留。
4. 图片处理前检查尺寸和对象引用，减少小图和共享图的重复解码。
